# Demo video: how it was made

- **Video:** https://youtu.be/s_W2hhFQJGc (v4, Nov 2, 2026). It replaces the earlier cut https://youtu.be/0LZBDRTz6PQ, which stays up but is superseded. The source file `agentaisle-demo-v4-grok.mp4` is kept out of git (see `.gitignore`). It is 1920x1080, 30 fps, H.264 + AAC, **2:47.8** (167.8 s, measured with ffprobe). Cover: `cover.png`. Sample frames in `frames/` are from the earlier cut.
- **What changed in v4:** the demo now uses a real model, Llama 3.3 70B on Cloudflare Workers AI, for the simulated shoppers and the ops assistant. The narration says so, the header shows the model, and the event log shows the "model" badge on model-written steps. The test count is now 109, and the stack line includes Workers AI.
- **Recorded:** Nov 2, 2026 (CT) from the live public demo, https://agentaisle-demo.kamalkatul92-kk.workers.dev, in a headless-server Chrome (Xvfb + puppeteer-core) captured with ffmpeg. PayPal **sandbox** only; Pecan Plume Coffee Co. is a **fictional** merchant.
- **Read-only:** no merchant token was used and nothing was clicked that changes data. The new row in shot 2 is the real hourly simulator run at 10:17 AM CT arriving on the live desk; the inspector then shows the model's negotiation messages. In shot 4 the cursor hovers Approve but does not click it. Shot 5 shows the Ops agent tab without sending a message, because chatting needs the merchant token.
- **Narration:** synthetic voice generated with xAI Grok Text to Speech (voice "Ara"). It does not imitate any real person. Lines that didn't change from the previous cut reuse its audio; the 8 changed lines were voiced the same way.
- **Shot 7 (terminal):** an on-screen replay of **real captured output**. `npm test` (109 passed, 5 skipped sandbox probes) and `npm run verify:grid` (54 rows checked, 0 mismatches, 25 unapproved orders already expired at PayPal) ran at 9:23 to 9:24 AM CT. The clip is labelled "Replay of real command output".
- **Shot 8:** an architecture card (redrawn from the README diagram, now with Workers AI) and the end card.
- **QA:** the final audio was transcribed with faster-whisper small and compared with the script line by line: 350 words, 0 errors. Loudness -16.2 LUFS integrated, -1.2 dBTP true peak.
- **Known caption glitch:** at 0:26 to 0:33 the burned-in caption breaks "Llama 3.3 70B" across two captions ("…Llama 3." then "3 70B…"). The spoken audio is correct. The caption splitter has been fixed for any later re-cut.
- Third-party marks shown are limited to the tools actually used (PayPal, AG Grid, Cloudflare).
